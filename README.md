# Pad6K2R

My first project — a 6-key, 2-rotary-encoder switch macropad.

## Components Used

| # | Component |
|---|---|
| 1 | Switches — Cherry MX 1.00u switch |
| 2 | Rotary Encoder (×2) |
| 3 | OLED 128×32 display |
| 4 | 1N914 diode (×6) |
| 5 | RGB LEDs — SK6812MINI (×10) |
| 6 | Microcontroller — Arduino Nano RP2040 Connect |
